# Παιδικός στο σπίτι

Ημερήσιο πρόγραμμα και θεματικές δραστηριότητες για παιδί προσχολικής ηλικίας (2,5–3 ετών),
φτιαγμένο για χρήση στο σπίτι. Ανοίγει στο κινητό και λέει τι κάνουμε **σήμερα**.

## Τι περιέχει

- **Σταθερή ημερήσια ρουτίνα** — ξύπνημα, προσευχή, γυμναστική, γεύματα, ύπνος, μπάνιο.
- **33 θεματικές** για έναν πλήρη χρόνο, αγκυρωμένες στο ορθόδοξο εορτολόγιο και στις εθνικές εορτές.
- **Δραστηριότητες** με υλικά και βήματα — μία πρωινή και μία απογευματινή κάθε μέρα,
  επιλεγμένες σταθερά από την ημερομηνία (ίδιες σε κάθε συσκευή).
- **Εορτολόγιο** με μια σύντομη εξήγηση κάθε γιορτής σε γλώσσα παιδιού.

## Τεχνικά

Στατικό site χωρίς build: `index.html` + `styles.css` + `app.js` και τέσσερα αρχεία JSON
στο `data/`. Καμία εξάρτηση, κανένα framework. Το περιεχόμενο αλλάζει επεξεργάζοντας
τα JSON — ο κώδικας δεν χρειάζεται να πειραχτεί.

| Αρχείο | Τι κρατάει |
| ------ | ---------- |
| `data/routine.json` | Το ημερήσιο πρόγραμμα, βήμα-βήμα |
| `data/themes.json` | Οι 33 θεματικές με ημερομηνίες, γιορτές και στόχους |
| `data/activities.json` | Οι δραστηριότητες ανά θεματική (`slot` A = πρωί, B = απόγευμα) |
| `data/feasts.json` | Το εορτολόγιο με κείμενο για παιδί |

Τοπική δοκιμή:

```
python3 -m http.server 8000
```

## Σημείωση

Το περιεχόμενο είναι λιτό εκ κατασκευής: καμία φωτογραφία, κανένα επώνυμο,
καμία τοποθεσία. Η σελίδα φέρει `noindex`.
